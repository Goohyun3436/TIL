## Overview

<img width="586" height="536" alt="Image" src="https://github.com/user-attachments/assets/c7467386-0343-4c1d-ad72-743c5d2b5212" />

- 비콘 기반 위치 관제 시스템을 구성하면서, 비콘 스캐너와 AP 장비를 하나의 세트로 하우징하는 작업을 진행하게 됐다.

- AP 장비가 AP 로도 쓰이고, Bridge Mode 로도 설명되고, Mesh 구성도 가능하다고 적혀 있어서 장비 역할을 정확히 이해할 필요가 있었다.

- 이번 정리는 비콘 스캐너와 함께 납품하는 AP 장비를 이해하기 위해, MAP5200-MESH 같은 산업용 AP 를 기준으로 AP 장비의 기본 역할, PoE Injector 가 왜 필요한지, Bridge Mode 와 Mesh Networking 이 어떻게 다른지 중심으로 공부한 기록이다.

> <strong>AP</strong>: 유선 네트워크를 무선 네트워크로 확장해주는 장비
> <strong>Bridge Mode</strong>: 서로 다른 네트워크 구간을 같은 네트워크처럼 이어주는 동작 방식
> <strong>Mesh</strong>: 여러 무선 노드가 서로 연결되어 넓은 영역을 하나의 무선망처럼 구성하는 방식

<br />

## 문제 상황

이번 작업은 <strong>비콘 기반 위치 관제 시스템에 들어갈 하드웨어 구성을 정리</strong>하는 과정에서 시작됐다. 비콘 스캐너와 AP 장비를 하나의 세트로 하우징하려다 보니, 단순히 "와이파이를 뿌려주는 장비" 정도로만 AP 를 이해해서는 구조를 정리하기가 어려웠다.

전원은 어떻게 넣는지, 백홀은 무엇인지, Bridge Mode와 Mesh 네트워킹은 무엇인지를 이해해야 설치 구조와 운용 방식을 설계할 수 있었다.

AP 장비는 <strong>MAP5200-MESH</strong> 를 사용하며, 장비 브로셔를 보니 아래의 지점에서 개념 정리가 필요하다고 느꼈다.

- 장비가 AP, Bridge, Mesh 를 모두 지원

- 전원 어댑터 대신 PoE Injector 로 전원을 주입

- 비콘 스캐너와 AP 를 한 하우징 안에 넣을 때, 어떤 전원 방식과 네트워크 연결 구조를 가져가야 하는지 판단이 필요

- Root 와 여러 Node가 서로 연결되는 Mesh

<br />

## AP(Access Point) 장비는 무엇을 하는가

새로운 무언가를 이해하려고 할때, 목적을 먼저 파악하면 이해하기 좋은 것 같다.

내가 이해한 AP 의 목적은 아래와 같다.

- 유선 네트워크를 <strong>무선으로 확장</strong>하는 역할을 한다. 스위치나 공유기에서 들어온 네트워크를 와이파이로 확장해준다.

- 네트워크 연결이 필요한 장비가 차량과 같이 <strong>이동하는 경우에 무선 통신</strong>을 구성할 수 있다.

- Mesh 또는 Bridge 기능을 지원하는 AP 계열 장비에서는, <strong>먼 거리</strong>에 설치된 장비 간 통신이 필요할 때 <strong>root 와 node 구조로 무선 연결</strong>을 구성할 수 있다.

- <strong>이미 구성된 네트워크에 무선 접속 지점을 추가</strong>하는 역할도 가능하다.

<br />

처음에는 공유기와 AP 를 비슷하게 생각했는데, 실제로는 역할 차이가 더 분명했다.

- 공유기는 보통 NAT, DHCP, 라우팅 같은 기능까지 같이 담당한다.

<br />

AP 장비의 목적을 이해하니까, 이번 납품하는 환경에서 Mesh 기능을 하는 AP 장비가 왜 필요한지 이해가 됐다.

- 사무실에 이미 구성된 네트워크가 있고 <strong>> 다른 대역의 네트워크 구성이 필요함.</strong>

- 비콘 기반의 위치 관제를 구성하려면, 넓은 영역에 무선 네트워크 환경이 이루어져야했고 <strong>> 네트워크 장비간의 거리가 멈.</strong>

- 센싱이 잘 되려면 비콘 수신기가 천장에 설치될 것이며 <strong>> 거리상 유선의 한계가 있을 것임.</strong>

- 메인 서버에 데이터 전송이 되어야 하니까 > <strong>Root AP 만 사무실과 유선 연결을 하면 서로 망을 연결할 수 있음.</strong>

관제 사무실에서부터 관제 영역까지 노드 구조를 적용하여 안정적인 무선 영역 확장을 위해 AP 를 설치하는 것이다.

즉, "인터넷을 만들어주는 장비"라기보다 <strong>"기존 네트워크를 무선으로 열어주는 장비"로 활용</strong>한 것이다.

<br />

## PoE Injector 는 무엇인가

스위치처럼 여러 포트를 가진 구조가 아니라, 전원선과 <strong>PoE 포트</strong>, <strong>LAN 포트</strong>로 단순한 구성이었다.

- <strong>LAN 포트</strong>: 스위치나 공유기 같은 상위 네트워크 장비와 연결되는 포트이다. 이 포트로는 데이터 신호가 들어온다.

- <strong>PoE 포트</strong>: 전원이 주입된 데이터 신호를 AP 쪽으로 보내는 포트이다. 이 포트를 통해 데이터와 전원을 함께 받는다.

PoE Injector 는 <strong>네트워크 장비 설치를 쉽게 하고 배선을 단순하게 만드는 전원 공급 보조 장치</strong>이다.

비콘 스캐너와 AP 를 하나의 하이박스 안에 하우징할 때에도 중요한 개념이었다. 전원 공급 방식을 어떻게 가져갈지에 따라 내부 배선 구조와 설치 난이도가 달라질 수 있기 때문이다.

<br />

## Bridge Mode 는 무엇인가

Bridge Mode <strong>네트워크 구간 두 개를 이어서 같은 네트워크 처럼 동작하게 만드는 방식</strong>이다. 라우터처럼 네트워크를 새로 나누는 것이 아니라, 두 구간을 같은 네트워크망으로 연결해준다.

AP 문서를 보다 보면 Bridge Mode 지원이라고 적혀 있는데, 이 말은 장비가 단순히 와이파이로 확장되는 것이 아니라, 무선 구간을 이용해서 두 네트워크 지점을 서로 연결하는 역할도 할 수 있다는 뜻이다.

예를 들어 아래 같은 구조를 생각할 수 있었다.

- 본관 스위치에 연결된 AP 하나

- 별관 쪽 AP 하나

- 둘이 무선으로 서로 연결

- 별관 쪽 장비들이 본관 네트워크와 이어짐

Bridge Mode 가 "커버리지를 넓히는 것" 자체보다 "네트워크 구간을 이어주는 것"에 초점을 뒀다.

즉, 이 개념을 활용하면 AP 장비로 관제 사무실의 메인서버와 관제 영역의 무선 네트워크 망을 연결할 수도 있다.

<br />

## 백홀(backhaul)은 무엇인가

back = 뒤로
haul = 끌다, 운반하다

뒤로 운반하다, 본선 쪽으로 다시 실어 나른다는 느낌이다.

- AP가 데이터를 받음

- 그 데이터를 상위 스위치나 메인 노드 쪽으로 다시 보냄

네트워크에서 백홀이라고 하면 AP 에서 받은 <strong>데이터를 메인 망 쪽으로 실어 나르는 연결</strong>이라고 이해하면 쉽다.

<br />

## Mesh Networking 은 무엇이 다른가

Mesh 는 <strong>여러 무선 장비가 서로 연결되어 하나의 넓은 무선망을 구성하는 방식</strong>이다.

예를 들어 메인 노드 하나가 있고, 다른 노드들이 그 메인 노드 또는 주변 노드를 통해 연결되면, 사용자는 하나의 무선망처럼 이용할 수 있다.

이 구조는 넓은 공간이나 유선 배선이 어려운 장소에서 특히 유용할 것 같다. 그래서 비콘 기반 위치 관제처럼 설치 지점이 넓게 퍼질 수 있는 환경에서는 Mesh 개념이 활용된다.

<br />

## 결론

AP 는 무선 접속 지점을 만드는 장비이고, PoE Injector 는 그런 AP 를 설치하기 쉽게 만드는 전원 공급 장치이다.

Bridge Mode 는 두 네트워크 구간을 이어주는 방식이고, Mesh 는 여러 무선 노드가 서로 연결되어 넓은 무선망을 만드는 구조이다.

<br />

## 느낀 점

- AP 장비를 그냥 와이파이 장비 정도로만 생각했는데, 거리의 한계, IP 점유의 한계, 움직이는 환경에서의 네트워킹 등 물리적인 요소를 해결해주는 네트워크 장비로서 이해가 됐다.

- 이번처럼 비콘 스캐너와 AP 를 함께 하우징하는 작업에서는 장비 단품 이해보다 전체 구성 이해가 더 중요하다는 점도 같이 느꼈다.
